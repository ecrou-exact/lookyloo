# API reference (`/api`)

Route `api_reference`, template `about/api.html`, script `js/api_reference.js`.

The flask-restx description of the API (`/swagger.json`) rendered by vitrine
`<vt-openapi variant="full">` (doc/ui/vitrine.md): endpoints grouped by
namespace, search, parameters, schemas, example requests (`<vt-http>`) and
authentication (API key in the `Authorization` header). Links to
`swagger.json`, the stock Swagger UI (`/doc/`, still there) and PyLookyloo.

The *API documentation* entry of the Help menu and the *API* link of the footer
point here.
